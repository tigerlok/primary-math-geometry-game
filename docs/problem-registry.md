# 题目登记表

记录用户补充的题目：它训练的思路、出处、在游戏里变成了哪些问法。
原题的文字和插图不放进仓库；游戏里的题一律重新出数、重画图。

状态说明：**待做** = 已登记未进游戏；**已上线** = 已做成题型并通过自动核对。

## 分类表（抽象思维专题）

归类依据是“解题时起决定作用的那一步”，不是书上的章节。新题先往这五类里放；放不进去再加新类，加之前先和发起人商量。

| 类别 | 一句话 | 在游戏里的位置 |
|---|---|---|
| 不算也能比 | 共同的量不参与比较 | 阶段 1 |
| 用字母写结论 | 答案是式子，不是数 | 阶段 2 |
| 不求也能算 | 单个量求不出，组合能求出 | 拓展栏（待做） |
| 特例归为一般 | 几个公式其实是一个 | 阶段 3（待做） |
| 变中找不变、写通项 | 量在变，关系不变；写出第 n 个 | 阶段 4–6（待做） |

每道题登记时写明：类别、关键一步、前置知识、计划的问法、是否适合做成随机题型、出处、状态。

## 拓展　不求也能算

类别：不求也能算。前置知识：阶段 2（用字母表示长度）、周长与面积公式。三道题都适合做成随机题型。


共同思路：单个长度求不出来，但它们的某个组合能求出来，而答案恰好只需要这个组合。
