# 进度与摘要

最后更新：2026-11-25

这份文件记录项目做到了哪里、为什么这样做、下一步是什么。每完成一批工作后更新。

## 一、项目由来

- 目的：提高小学生的数学抽象思维。切入点是把几何和“用字母写式子”结合起来，从比较等高图形（正方形、矩形、平行四边形、三角形、梯形）的面积开始，分阶段提高，最终走到写通项。
- 对象：小学五年级，已学过五种图形的面积公式。
- 设备：平板，横屏。
- 第一位使用者是发起人的女儿。她原先不爱数学，使用后每天主动要过关。
- 发起人希望公开分享，帮助更多孩子，所以仓库公开、MIT 许可。

## 二、整体路线

| 阶段 | 核心 | 状态 |
|---|---|---|
| 阶段 0　想清楚公式 | 割补、数格子，弄清公式来历 | 已上线（2 关） |
| 阶段 1　不算也能比 | 等高时只比“底”这一部分 | 已上线（4 关 + 大关一） |
| 阶段 2　用字母说话 | 字母当作任意数；拼式子作答 | 已上线（7 关 + 大关二），**发起人和女儿尚未试用** |
| 拓展　不求也能算 | 单个长度求不出，组合能求出 | 待做，首批三题已登记 |
| 阶段 3　统一到梯形 | 拖动梯形变形，五个公式归为一个 | 待做 |
| 阶段 4　字母是会变的量 | 顶点滑动、单量变化、补偿 | 待做 |
| 阶段 5–6　通项 | 等距平行线把三角形切成 n 层，面积比 1 : 3 : 5 : … | 待做 |

贯穿的三条设计原则：先预测后验证；字母的含义逐级升级（未知的数 → 任意数 → 变量 → 序号）；每种典型错误有对应的讲解。

## 四、已定的约定

- **补题机制**：发起人随时发来见过的好题。处理四步：核对原解 → 归类 → 改造成可随机换数的题型 → 登记，确认后进游戏。书上原题的文字和插图不进仓库。
- **拓展栏**定名“拓展　不求也能算”，与主线方法相同：不需要知道某条边的具体值。
- **归类由 Claude 做**：发起人只管发题和出处（书名、作者、页码）。归类方法和每题要给出的五项，写在 `CLAUDE.md` 的“用户发来例题时怎么处理”一节；分类表在题目登记表开头。
- **署名**：由 tigerlok 与 Claude（Anthropic 的 AI 助手）共同构建。
- **上传流程**：Claude 把改动传到一个待审副本，发起人在 GitHub 上点“合并”后才正式生效。
- **不考虑微信的链接预览**：微信不读取通用的分享预览标记，链接卡片可能不显示封面图。发起人决定不为此接入微信的开发接口。

## 八、更远的打算

抽象思维专题告一段落后，发起人打算开始其它专题，补题与归类的机制原样沿用。届时先向发起人提出该专题的分类框架和形式建议，确认后再做。两件事到时再定：

- 放在哪里：现在的仓库名带 geometry（几何）。新专题若不是几何，可以另建仓库，也可以把现有仓库改名后合在一起。
- 是否还用“闯关加随机出题”的形式：几何题适合；有些专题未必适合，要按专题特点重新设计。
